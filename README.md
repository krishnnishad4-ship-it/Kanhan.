# Kanhan Shopping Website

Frontend-only multi-page e-commerce website.

## Upload to GitHub Pages
Keep `index.html` in the repository root.
Upload all HTML files plus the `css` and `js` folders.
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Important
Login, registration, orders and online payments are demo UI only. A real shopping site needs a backend/database and payment provider.
